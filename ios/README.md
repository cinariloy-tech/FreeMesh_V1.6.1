# Free Mesh iOS

Derleme Codemagic'te `ios-ipa` workflow'u ile yapılır. Sonuç imzasız `FreeMesh.ipa` dosyasıdır.

iPhone'a kurmak için (ücretsiz Apple ID):
1. Bilgisayara Sideloadly'yi kur (sideloadly.io).
2. iPhone'u USB ile bağla, Sideloadly'de cihazını seç.
3. `FreeMesh.ipa` dosyasını sürükle, Apple ID'ni gir.
4. Kurulumdan sonra iPhone'da Ayarlar > Genel > VPN ve Cihaz Yönetimi bölümünden geliştirici profilini "Güven" olarak işaretle.
5. Uygulama 7 gün sonra yeniden imzalanmalı (Sideloadly ile tekrar kurarsın).

Not: Bu kod Linux'ta derlenmedi. Codemagic derlemesinde hata çıkarsa log'u paylaş.
